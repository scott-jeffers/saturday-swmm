Saturday-SWMM (portable)
========================

No installation needed.

1. Unzip this folder anywhere you can write to (e.g. Documents\Saturday-SWMM).
   Avoid "Program Files". Keep the folder together.
2. Double-click  Saturday-SWMM.cmd
   Your browser opens at http://127.0.0.1:8765/  (a free port is chosen if
   8765 is busy). Everything runs on this computer; nothing is uploaded.
3. Keep the black console window open while you work. Close it, or use
   Quit in the app, to stop.

Windows SmartScreen may warn the first time because the launcher is not
code-signed: choose "More info" -> "Run anyway".

Engines included: OpenSWMM 6 (default, 1D + 2D), EPA SWMM 5.2 via PySWMM,
and DEM flow accumulation.

Updating: the app tells you when a new release is available (Settings ->
About). Download the new zip, unzip it next to the old one, and start the
new Saturday-SWMM.cmd. Your projects live in your own folders, so nothing
needs to be migrated. Delete the old folder when you are happy.

Try it: on the Projects page, click one of the Examples buttons (a small sample
model, and the Bellinge network from Odense, Denmark, in 1D and 2D).
